레일픽(RailPick) 데이터 삭제 안내

앱: 레일픽(RailPick) — Android 기차 예약 보조 앱
개발자: RailPick
문의: j23488sh@gmail.com

레일픽(RailPick) 이용자는 본인이 앱을 이용하면서 수집된 개인정보의 전체 또는 일부 삭제를 언제든지 요청할 수 있습니다. 본 페이지는 데이터 삭제 절차와 삭제·보관되는 데이터 유형 및 보관 기간을 안내합니다.

1. 데이터 삭제 요청 방법 (3가지 경로)

1.1 앱 내 계정 삭제 (권장)

  1. 레일픽 앱을 실행합니다.
  2. 설정 메뉴로 이동합니다.
  3. 계정 관리 또는 로그인 정보 섹션에서 계정 삭제 항목을 선택합니다.
  4. 안내에 따라 삭제를 확정합니다.

계정 삭제 시 Firebase Authentication 계정과 동기화된 사용자 데이터 (승차권, 앱 설정, 기기 목록, FCM 토큰 등) 가 즉시 삭제되며, 카카오 / 네이버 / Google 소셜 로그인의 앱 연결도 함께 해제됩니다.

1.2 앱 데이터 초기화 (기기 내 데이터)

  1. 레일픽 앱을 실행합니다.
  2. 설정 메뉴 → 앱 데이터 초기화 항목을 선택합니다.
  3. 기기 내부에 저장된 모든 정보 (SRT/코레일 로그인 세션, 즐겨찾기, 검색 설정, 알림 설정 등) 가 즉시 삭제됩니다.

또는 Android 시스템 설정 → 앱 → RailPick → 저장공간 → 데이터 삭제 를 통해서도 동일한 결과를 얻을 수 있습니다.

1.3 이메일 문의 (서버 영구 보관 데이터의 추가 삭제 요청)

아래 영구 보관 데이터 (결제 이력 / 친구 추천 이력 / 동의 이력 등) 의 삭제를 별도로 요청하시려면 다음 이메일로 연락해 주시기 바랍니다.

  • 이메일: j23488sh@gmail.com
  • 요청 시 기재 사항: 가입에 사용한 이메일 주소 (또는 기기 식별자 해시 일부), 삭제 요청 항목
  • 처리 기간: 요청 접수 후 영업일 기준 10일 이내 (한국 개인정보보호법 §36 권리행사 기한)

2. 삭제되는 데이터 유형 및 보관 기간

2.1 계정 삭제 / 앱 데이터 초기화 시 즉시 삭제

데이터 유형 저장 위치 삭제 시점
SRT/코레일 로그인 세션 정보 기기 내부 (암호화 저장) 앱 데이터 초기화 시 즉시
예약 대기 내역, 즐겨찾기, 검색 설정, 알림 설정 기기 내부 + Firebase Firestore (동기화 시) 계정 삭제 시 즉시 (서버) / 앱 데이터 초기화 시 즉시 (기기)
로그인 계정 (Firebase Authentication) Firebase Authentication 계정 삭제 시 즉시
연결된 기기 목록, 푸시 알림 토큰 (FCM) Firebase Firestore 계정 삭제 시 즉시
소셜 로그인 앱 연결 (카카오 / 네이버 / Google) 각 소셜 로그인 제공자 계정 삭제 시 자동 연결 해제

2.2 자동 만료되는 데이터

데이터 유형 저장 위치 보관 기간
앱 무결성 검증 이력 (Play Integrity verdict) Firebase Firestore (integrity_verdicts) 30일 후 자동 삭제 (rolling window)

2.3 어뷰징 차단·법적 의무 목적의 영구 보관 데이터

다음 데이터는 어뷰징 차단·환불 처리 정확도·분쟁 예방 등 정당한 이익 보호를 위해 영구 보관되며, 이용자가 이메일 문의 (1.3) 를 통해 명시적으로 삭제를 요청한 경우에 한해 삭제됩니다.

데이터 유형 저장 위치 보관 사유
결제 이력 (orderId hash, 결제 상품, 환불 여부 등 — 카드 정보 미포함) Firebase Firestore (payments, device_payments) 환불 처리 / 보상 회수 정확도 / Google Play 환불 알림(RTDN) 추적
친구 추천 이력 (추천 코드, 보상 지급/회수 기록) Firebase Firestore (referral_codes / referrals / referral_rewards) 어뷰징 차단 / 보상 회수 추적
분리 동의 이력 (스마트 예약 보조 / Play Integrity / 단말 식별자 / 결제 fingerprint / 친구 추천) Firebase Firestore (consent_logs) 한국 개인정보보호법 §22 요건에 따른 동의 이력 보관 / 분쟁 예방
무료 체험 관리 정보 (기기 식별자 해시, 최초 설치 시간) Firebase Firestore (device_trials) 재설치를 통한 무료 체험 중복 사용 방지

3. 데이터 삭제와 관련된 유의사항

  • 계정 삭제 후에는 동일 소셜 계정으로 재가입 시에도 이전 동기화 데이터·승차권 정보가 복원되지 않습니다.
  • SRT / 코레일 자체 계정 및 예매 이력은 본 앱이 관리하지 않으며, 해당 서비스에 직접 문의하셔야 합니다.
  • 이메일 문의로 영구 보관 데이터의 삭제를 요청하시는 경우, 어뷰징 차단·환불 처리 등 정당한 이익이 우선되는 항목은 한국 개인정보보호법 §37 ②항에 따라 삭제가 제한될 수 있으며, 이 경우 사유를 회신드립니다.
